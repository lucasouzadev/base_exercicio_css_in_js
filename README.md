# Exercício 3 — EBAC Jobs com Styled Components

Fork do projeto [ogiansouza/base_exercicio_css_in_js](https://github.com/ogiansouza/base_exercicio_css_in_js).

A estilização dos componentes FormVagas, Cabecalho, Hero, Vaga e ListaVagas foi convertida de CSS Modules para Styled Components. Os estilos globais usam `createGlobalStyle`; o container e as cores compartilhadas ficam em `src/styles.ts`. Os arquivos CSS substituídos foram removidos.

Foram preservados os textos, cores, imagem, espaçamentos, efeitos hover, breakpoints e a pesquisa do projeto original. Os links de candidatura permanecem os placeholders do material de apoio.

## Executar

```sh
npm ci
npm start
```

Abra http://localhost:3000.

```sh
npm run build
```
